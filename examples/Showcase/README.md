# OrbitalNote showcase vault

Open this folder as a workspace in **0.1.0-preview.9 or newer**. Start
with **00 Welcome.org**. Copy the folder first if you want to experiment freely.

Includes local PNG imagery, two Mermaid diagrams, inline/display math, a LaTeX
math block, code, tables, links, custom task states, priorities, properties,
tags, and dated tasks. Planning examples use September 28–October 2, 2026.

Rich previews use bundled Mermaid and KaTeX; no network is required. The image
lives in `attachments/fieldwork.png`. Current Sync transfers Org notes only,
so copy attachments separately between devices.

Preview.8 predates the diagram/math rendering and heading-menu improvements.
