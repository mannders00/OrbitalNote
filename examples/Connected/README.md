# Connected notes: Dispatch

Open this folder as a workspace, then open **Dispatch.org** and show the right
sidebar. **Local graph** is its last section. Click a node or linked-note row to
explore; the graph recenters on the note you open.

Dispatch is a small fictional support-ticket service. Its neighborhood includes
architecture, queue sizing, observability, a release plan, and a daily journal.
Solid connections are outgoing links, dashed connections link back here, and
accented connections link both ways. The list labels each relationship explicitly.

Try **Architecture.org** next: it connects the project to a design decision in
the `Decisions` folder, demonstrating workspace-relative links in both directions.
**Weekend.org** is deliberately unlinked so you can see the empty state.

**Systems-notebook.org** is the compact rich-reading example used in the theme
screenshots: nested TODOs, planning metadata, a capacity equation, a Mermaid
diagram, a checklist, and a useful graph neighborhood.

All content is ordinary Org text. No account or Sync is required. Dates are
fictional examples for October 5–9, 2026.
